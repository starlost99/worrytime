# Worry time 🌸

A small, private, dusty-pink tool for a daily 10-minute "worry time".

Write down what's worrying you, decide whether you can act on it (first small step) or not ("if the worst happens, I will…"), then close the session with a short ritual: *it's written down, this is a fear, not reality, I'm allowed to stop for today.*

## Features
- 10-minute optional timer
- Two paths per worry: act vs. out of my hands
- Closing screen to "put away" the day's worries
- Saved per day in your browser's `localStorage` (nothing leaves your device)
- Dusty pink theme with automatic dark mode
- Single file, no dependencies, works on mobile

## Use it
Open `index.html` in a browser, or host it free with GitHub Pages:
Settings → Pages → Deploy from branch → `main` / root.

## Note
This is a self-help aid, not a substitute for professional support. If worry or grief is taking over your sleep or daily life, a psychologist or CBT therapist can help.
